## 🚀 Technical Architecture Section

### System Architecture
```
Security Hub (691 Findings) → CloudWatch Events (Weekly Schedule) → 
AWS Lambda (Enhanced Processing) → S3 Reports + SNS Email Notifications
```

### Technology Stack
- **AWS Lambda**: Python 3.11 serverless compute
- **CloudWatch Events**: Automated scheduling (Mondays 9 AM UTC)
- **Amazon S3**: Encrypted report storage with presigned URLs
- **Amazon SNS**: Email notification system
- **AWS Security Hub**: Security findings data source
- **Infrastructure as Code**: CloudFormation templates
- **Python**: boto3, pandas, openpyxl libraries

### Key Features
- **Automated Security Analysis**: Processes all active Security Hub findings via pagination
- **Executive Reporting**: Multi-sheet Excel reports with summary dashboards
- **Severity-Based Alerting**: Identifies and highlights high/critical security issues
- **Email Notifications**: SNS-based alert system with secure download links
- **Scheduled Execution**: Zero-maintenance weekly automation
- **Professional Formatting**: Auto-sized columns, styled headers, color-coded severity
