# AWS Security Hub to Excel Pipeline

Serverless Lambda function that extracts AWS Security Hub findings and generates professional Excel reports.

## Results
- 140+ Security Hub findings processed
- Professional Excel reports with formatting
- Deployed via CloudFormation

## Tech Stack
- AWS Lambda (Python 3.11)
- AWS Security Hub
- openpyxl
- CloudFormation
- S3
